# Visual Authority Addendum for the Grand Design Contract

## Status
This addendum clarifies the correct relationship between the final contract and the mockup package.

## Rule
The **original WayPoint mockup library** and the **final feature-page mockup package** are the primary visual-reference lineage for:
- composition,
- visual density,
- imagery treatment,
- responsive character,
- premium finish,
- material depth,
- map / globe prominence,
- overall aesthetic continuity.

The grand design contract remains the authority for:
- information architecture,
- product scope,
- feature placement,
- navigation model,
- UX principles,
- motion philosophy,
- accessibility expectations,
- areas where later decisions intentionally changed earlier mockups.

## Interpretation rule for Claude / Fable
Implement from these references **faithfully but flexibly**.

That means:
- preserve the same design family and premium feel,
- preserve the page-specific structure and visual intent,
- allow implementation judgment where exact pixel matching is unnecessary,
- do not regress to a flatter, weaker, or more generic aesthetic.

## Explicit anti-drift rule
Do not:
- simplify these references into generic dashboards,
- swap major photo-led surfaces for abstract placeholder art,
- reintroduce retired visual systems,
- overload pages with decorative filler copy, random quotes, or AI-sloppy ornament.
