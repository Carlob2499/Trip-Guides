`Plate` mounts a photograph into the sheet. Use it for guide covers, hub cards, lightboxes, and any scan or map image.

```jsx
<Plate src={guide.cover} alt="Gyeongbokgung" caption="plate · commons" />
```

Never put a scrim on it, never set type on it, never give it a graticule (tried in R3, cut — at card scale it read as dirt on the lens), and never put corner ticks on anything that is not evidence.
