`PlateLine` sits beneath the masthead plate and its text column.

```jsx
<PlateLine reading="Seoul · Daejeon · Busan" note="Next: KTX 08:30 → Daejeon" stamp="✓ 30 jul" meta="21/37 stops · 4 to book · print sheet" />
```

R5 replaced the coordinate pair and `PLATE 02 — KR` with the trip's cities and its next leg — same treatment, more useful mid-trip. Guide numbering is retired from guide surfaces; the hub still indexes by `sheetOrdinal`.
