`Stamp` marks a check date, a source, or a plate caption. Use it wherever a fact needs its provenance stated at reading size.

```jsx
<Stamp>✓ checked 18 jul 2026</Stamp>
<Stamp tone="ochre">⚠ several lines are personal estimates</Stamp>
```

Never render a stamp below 0.82rem, and never in Literata — it is notation, not prose.
