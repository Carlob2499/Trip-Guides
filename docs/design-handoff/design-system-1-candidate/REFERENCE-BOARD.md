# DS1 calibration reference board

> References are evidence and inspiration, not authority. This board deliberately uses only
> current repository material plus the creator-mandated type candidates. It does not assemble
> a mood-board “style soup,” and it never licenses copying an entire brand.

## Reference discipline

- Use the same realistic content and state across alternatives.
- Name the one quality being studied before using a reference.
- Do not import a reference's entire visual identity.
- Mark missing evidence instead of searching broadly or inventing a precedent.
- Product truth and the candidate constitution outrank every item on this board.
