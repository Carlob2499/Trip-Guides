# Visual calibration brief

> High-fidelity comparison only. Do not edit production UI, buy fonts, rewrite traveler facts,
> or treat a persuasive mock as approval. Use realistic Waypoint content and show mobile and
> desktop as siblings.

Every gate returns exactly one state:

- `LOCK` — creator approves it for DS1.
- `REVISE` — direction is right; named changes are required.
- `REJECT` — direction is not DS1.
- `UNRESOLVED` — evidence is insufficient; do not infer a decision.

## Gate 1 — Typography

**Question.** Which type system gives Waypoint editorial character, fast operational reading,
and resilient multilingual/data performance?

**Compare at minimum.**

1. Literata + Source Sans 3 (current control)
2. Signifier + Söhne
3. GT Alpina + GT America
4. ABC Arizona variable

Do not purchase or license fonts. If files are unavailable, use legitimate specimens or clearly
label a fidelity gap; do not substitute a lookalike and claim a decision.

**Must not change.** Copy, facts, hierarchy of traveler tasks, verification meaning, 320px
reflow, accessible text scaling, dark mode, or offline/self-hosted production requirements.

**Test content/screens.** Atlas title; Today; dense train directions; restaurant content;
Trip Split; long Guide prose; map labels; reservation detail; dark mode; mobile field view.

**Decision criteria.** Distinctive Waypoint identity; glance speed; long-form comfort; tabular
data clarity; dense operational legibility; multilingual resilience; hierarchy across modes;
realistic self-hosting/licensing path.

## Gate 2 — Geometry

**Question.** What deliberate shape system expresses modern spatial utility plus editorial
depth without becoming generic card UI?

**Compare approximately three systems.**

1. restrained editorial radii with square evidence and pill controls;
2. spatial-functional differentiation across operational containers, editorial frames, and controls;
3. freer editorial canvases paired with a compact bounded-tool geometry.

Each option must use one coherent scale and name every role. Do not smuggle in random per-component
values.

**Must not change.** Evidence semantics, obvious clickability, target sizes, focus treatment,
safe areas, hostile-content containment, or the fixed product IA.

**Test content/screens.** Today operational cards; Guide editorial spread; Split ledger/form;
reservation; provenance popover/sheet; Map overlay; empty and warning states.

**Decision criteria.** Recognizable Waypoint silhouette; hierarchy; operational clarity;
editorial freedom; cross-surface coherence; mobile space efficiency; absence of “card soup.”

## Gate 3 — Provenance

**Question.** How should DS1 show verification, uncertainty, staleness, conflicts, and evidence
depth without making every sentence visually noisy?

**Compare approximately three approaches.**

1. selective inline marks with a focused popover/sheet;
2. section-edge or marginal verification summaries with deep evidence on demand;
3. contextual status bands/rows that intensify only for stale, conflicting, or unconfirmed state.

All three must demonstrate fresh, ageing, stale, approximate, unconfirmed, conflicting, and
no-public-source states.

**Must not change.** Claim/source/date traceability; honest gaps; non-color meaning; click/focus
access; raw traveler critiques never rendered; no invented fact or source.

**Test content/screens.** Dense train direction; restaurant price/hours; Guide prose; Today
warning; reservation; source detail; stale/offline conflict.

**Decision criteria.** Trust at a glance; uncertainty prominence; low routine noise; depth in
one intentional action; field readability; assistive semantics; truthful failure state.

## Gate 4 — Mobile + desktop navigation/composition

**Question.** How should the fixed Today · Itinerary · Map · Split · Guide IA persist as sibling
mobile and desktop systems while chrome moves, compresses, or docks with context?

**Must not change.** Five destination names/order; Search and SOS global; active trip opens to
Today; group members cannot rewrite itinerary; no adaptive ranking; Map remains a major surface;
mobile loses competition, not capability.

**Test content/screens.** Active-trip Today; pre-trip planning; Guide reading; Map comparison;
Split entry/settlement; Search result; SOS; deep scroll; overlay open; offline/uncertain state;
desktop comparison workspace and 320–430px mobile.

**Decision criteria.** Orientation; one-handed reach; stable destination recognition; fast
return to current task; useful desktop relationships; no hidden capability; safe-area behavior;
keyboard/screen-reader clarity; context-preserving transitions.

Prototype navigation choreography, not an adaptive/four-slot ranking revival.

## Gate 5 — Motion

**Question.** What motion vocabulary makes routine actions fast and spatially coherent while
allowing one memorable geographic/spatial moment?

Show both:

- routine state changes, destination transitions, overlays, and feedback; and
- one flagship spatial transition, such as Atlas/Map/Guide continuity.

Also show the complete reduced-motion behavior side by side.

**Must not change.** Task availability; content/fact meaning; instant operational comprehension;
input responsiveness; offline behavior; reduced-motion completeness; performance discipline.

**Test content/screens.** Today→Map; Map→Guide place; navigation docking/compression; Split add;
provenance open/close; one flagship Atlas transition; reduced motion for each.

**Decision criteria.** Spatial continuity; immediate response; restraint during routine work;
earned cinematic value; no layout-jank; transform/opacity path where applicable; battery/frame
budget; complete reduced-motion comprehension.

## First Claude `/design` canvas set

Build these as one high-fidelity comparison set, not gray wireframes:

1. **Identity reference** — DS1 proportions, registers, palette foundation, and anti-generic cues.
2. **Typography shootout** — all minimum candidates on identical realistic content.
3. **Shape/geometry systems** — approximately three coherent systems on the same components.
4. **Provenance systems** — approximately three approaches across healthy and adverse states.
5. **Photography/editorial Guide composition** — varied crops, gallery/full-width possibilities,
   text/visual equality, and evidence photography as one subtype.
6. **Mobile/desktop sibling compositions** — same capabilities, different prioritization.
7. **Fixed persistent navigation behavior** — Today · Itinerary · Map · Split · Guide plus Search/SOS.
8. **Routine vs flagship motion + reduced motion** — comparable storyboards or runnable states.
9. **Stress test** — Today, Guide, Split, Map, reservation, and offline/uncertain state at realistic density.

## Calibration handoff

For each gate, return:

- the compared alternatives;
- the same content and state across alternatives;
- accessibility/performance caveats;
- creator outcome (`LOCK`, `REVISE`, `REJECT`, `UNRESOLVED`); and
- the exact rule/token/component implications **only if locked**.

Do not convert locked visuals into production code in the calibration session unless the
creator separately authorizes an implementation phase.
